<h1 class="heading-element">🚀 Install</h1>

<div class="markdown-heading">
<h2 class="heading-element">System</h2>
</div>
<blockquote>
<p><strong>Note</strong>: The game system is compatible with Foundry&nbsp;<strong>V14</strong>.</p>
</blockquote>
<ol>
<li>Go to the setup page in Foundry and choose&nbsp;<code>Game Systems</code></li>
<li>Click the&nbsp;<code>Install System</code>&nbsp;and search for "Outside The Wire", or paste in this&nbsp;<a href="https://github.com/hodpub/outside-the-wire/releases/latest/download/system.json" target="_blank" rel="nofollow noopener">manifest link</a></li>
<li>Create a&nbsp;<code>Game World</code>&nbsp;using the Outside The Wire system and start it</li>
